# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform for developing, deploying, and operating applications and services. It provides infrastructure, storage, databases, analytics, artificial intelligence, machine learning, networking, security, and developer tools.

## Global Infrastructure

Google Cloud organizes its infrastructure into **regions and zones**. Regions are geographic areas containing zones, while zones provide separate failure domains within a region. Google Cloud infrastructure is available across North America, South America, Europe, Asia, the Middle East, and Australia. This geographic distribution helps organizations improve availability, reduce latency, and meet workload location requirements.

## Cloud Management Console

The **Google Cloud Console** is a browser-based graphical interface for managing Google Cloud resources. It provides access to projects, resources, billing information, activity, and Google Cloud Shell. Users can also manage services through the Google Cloud CLI and APIs.

## Four (4) Core Services

1. **Compute Engine** – Provides configurable virtual machines and bare-metal instances for running workloads.

2. **Cloud Storage** – Provides secure, durable, and scalable object storage.

3. **BigQuery** – Provides a cloud data warehouse and analytics platform for analyzing large datasets.

4. **Cloud Run** – A fully managed serverless platform for running applications and containers without managing the underlying infrastructure.

## Three (3) Advantages

1. **Strong Data and Analytics Capabilities** – Google Cloud provides services such as BigQuery for large-scale data analytics.

2. **Scalable and Global Infrastructure** – Regions and zones support scalable applications while helping organizations address availability and latency requirements.

3. **Developer-Friendly and Serverless Options** – Services such as Cloud Run allow developers to deploy applications while minimizing infrastructure management.

## Typical Enterprise Use Cases

- Data warehousing and business intelligence.
- Hosting websites, APIs, and cloud-native applications.
- Running containers and microservices.
- Artificial intelligence and machine learning workloads.
- Large-scale data processing and analytics.
- Application modernization and cloud migration.
