# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is recommended for the startup because it offers a wide range of cloud services that can support a mobile application as the company grows. Its pay-as-you-go pricing model can help the startup control costs because it only pays for the resources it uses. AWS also provides scalable services that can automatically handle increases in users and application traffic. This makes AWS suitable for a startup with a limited budget and plans for rapid growth.

### Recommended Services

- **Amazon EC2** – Provides scalable virtual servers for running application backends.
- **Amazon S3** – Provides scalable storage for images, files, backups, and other application data.
- **Amazon RDS** – Provides managed relational databases for storing application information.
- **AWS Lambda** – Allows the startup to run application code without managing servers.

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice for the university because it integrates well with the Microsoft technologies that the university already uses. Azure can connect with existing Windows Server environments and Microsoft 365 services, making cloud migration easier. Microsoft Entra ID can also work with the university's existing identity and access management environment. This allows the university to gradually migrate services while maintaining compatibility with its current Microsoft infrastructure.

### Recommended Services

- **Azure Virtual Machines** – Allows the university to run Windows Server and Linux workloads in the cloud.
- **Microsoft Entra ID** – Provides cloud-based identity and access management and integration with Microsoft services.
- **Azure SQL Database** – Provides a managed database service for university applications.
- **Azure Blob Storage** – Provides cloud storage for documents, files, backups, and other data.

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform (GCP) is recommended because it has strong capabilities in Artificial Intelligence, Machine Learning, and high-performance computing. Google Cloud provides specialized infrastructure and AI services that can support researchers developing demanding machine learning applications. Its AI and data services can help researchers train, deploy, and manage machine learning models. GCP also provides Kubernetes services that are useful for managing containerized AI and research workloads.

### Recommended Services

- **Google Compute Engine** – Provides configurable virtual machines for high-performance computing workloads.
- **Vertex AI** – Provides tools for developing, training, deploying, and managing machine learning models.
- **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for deploying and managing containerized applications.
- **Cloud Storage** – Provides scalable storage for datasets, models, research files, and backups.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is recommended for the global e-commerce company because of its extensive global infrastructure and scalable services. AWS provides multiple Regions and Availability Zones that can help the company maintain highly available applications for customers around the world. Services such as Amazon EC2 Auto Scaling can automatically adjust computing resources based on demand. AWS also provides load balancing, databases, storage, and content delivery services that are suitable for a large-scale e-commerce platform.

### Recommended Services

- **Amazon EC2 Auto Scaling** – Automatically increases or decreases computing capacity based on application demand.
- **Elastic Load Balancing (ELB)** – Distributes incoming traffic across multiple application resources.
- **Amazon S3** – Provides scalable and durable storage for product images, files, backups, and other data.
- **Amazon RDS** – Provides managed relational databases for customer, product, and transaction information.
- **Amazon CloudFront** – Delivers website content to users through a global content delivery network.

## Multi-Cloud Decision Matrix

The following decision matrix recommends the most appropriate cloud platform based on different business requirements.

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| **Startup Company** | **AWS** | AWS provides a wide range of services, flexible pricing options, and scalable infrastructure that can support startups as they grow. |
| **Enterprise Organization** | **AWS** | AWS offers a broad selection of enterprise services, global infrastructure, security features, and scalability for large organizations. |
| **Microsoft Environment** | **Microsoft Azure** | Azure provides strong integration with Microsoft products such as Windows Server, Microsoft 365, Microsoft Entra ID, and SQL Server. |
| **AI / Machine Learning** | **Google Cloud Platform (GCP)** | GCP provides powerful AI and machine learning services such as Vertex AI and supports high-performance computing for AI workloads. |
| **Kubernetes Deployment** | **Google Cloud Platform (GCP)** | GCP provides Google Kubernetes Engine (GKE), a managed Kubernetes service developed around Google's extensive experience with containerized applications. |
| **Global Web Application** | **Amazon Web Services (AWS)** | AWS provides extensive global infrastructure, automatic scaling, load balancing, and content delivery services suitable for applications serving users worldwide. |
