# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides on-demand services for computing, storage, databases, networking, analytics, security, and other IT needs. AWS uses a pay-as-you-go model, allowing organizations to use cloud resources without purchasing and maintaining physical infrastructure.

## Global Infrastructure

AWS organizes its infrastructure into geographic **Regions** and **Availability Zones (AZs)**. Each Region contains multiple physically separate Availability Zones. This helps organizations design applications with high availability, reliability, and fault tolerance. AWS also provides edge and low-latency infrastructure such as CloudFront, Local Zones, and Wavelength Zones.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services. It allows users to create and manage cloud resources, select AWS Regions, monitor services, manage users, and review billing information.

## Four (4) Core Services

1. **Amazon EC2 (Elastic Compute Cloud)** – Provides resizable virtual computing capacity for running applications and workloads.

2. **Amazon S3 (Simple Storage Service)** – Provides scalable object storage for files, backups, application data, and other objects.

3. **Amazon RDS (Relational Database Service)** – Provides managed relational databases while reducing the administrative work required to operate database servers.

4. **AWS Lambda** – A serverless compute service that runs code in response to events without requiring users to manage servers.

## Three (3) Advantages

1. **Scalability** – Resources can be increased or decreased according to workload requirements.

2. **Global Availability** – Applications can be deployed in different Regions and Availability Zones to improve availability and reach users in different locations.

3. **Pay-as-you-go Pricing** – Organizations can use cloud resources without large upfront investments in physical hardware.

## Typical Enterprise Use Cases

- Hosting websites, web applications, and APIs.
- Storing backups, documents, media, and large datasets.
- Running business databases and enterprise applications.
- Data analytics and machine learning workloads.
- Disaster recovery and backup infrastructure.
- Application modernization and migration from on-premises data centers.
