# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's global cloud computing platform for building, deploying, and managing applications and IT workloads. Azure provides services for computing, storage, databases, networking, analytics, artificial intelligence, security, and application development.

## Global Infrastructure

Azure uses a worldwide infrastructure made up of **regions, datacenters, and availability features**. Organizations can select suitable regions to meet requirements related to latency, availability, data residency, and compliance.

## Cloud Management Console

The **Azure portal** is a web-based management console for creating, managing, and monitoring Azure resources. It provides a graphical interface for services and resources, dashboards, Cloud Shell, notifications, settings, support, and cost monitoring.

## Four (4) Core Services

1. **Azure Virtual Machines** – Provides virtualized computing resources for running Windows or Linux workloads in the cloud.

2. **Azure Blob Storage** – Provides object storage for large amounts of unstructured data such as documents, images, videos, and backups.

3. **Azure SQL Database** – A managed relational database service based on Microsoft SQL Server technologies.

4. **Azure Functions** – A serverless compute service for running event-driven code without managing the underlying servers.

## Three (3) Advantages

1. **Microsoft Ecosystem Integration** – Azure integrates strongly with Microsoft products and technologies such as Windows Server, Microsoft Entra ID, and Microsoft 365.

2. **Global Infrastructure** – Its worldwide regions and datacenters support applications that need geographic reach, low latency, and data-residency options.

3. **Hybrid Cloud Flexibility** – Azure supports integration with on-premises environments and provides tools for managing diverse infrastructure and workloads.

## Typical Enterprise Use Cases

- Hosting enterprise websites and business applications.
- Running Windows and Linux virtual machines.
- Enterprise database hosting and data management.
- Backup, disaster recovery, and business continuity.
- Hybrid cloud integration with on-premises systems.
- Data analytics, artificial intelligence, and application modernization.
