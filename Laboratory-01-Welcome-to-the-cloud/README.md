# Laboratory-01-Welcome-to-the-Cloud

## Mission Overview

This laboratory mission focused on becoming familiar with the Linux environment and preparing a workspace for cloud-related activities. The goal was to explore the system, identify important hardware and software information, and organize files and folders using the Linux terminal.

## Objectives

* Identify the Linux distribution and kernel version.
* Check the CPU information of the system.
* Determine the total memory and available disk space.
* Create and organize folders inside the home directory.
* Create and view a Markdown file using the terminal.
* Practice basic Linux commands and terminal navigation.

## Activities Performed

1. Investigated the Linux environment and checked the Linux distribution.
2. Checked the kernel version.
3. Viewed the CPU information.
4. Checked the total system memory.
5. Checked the available disk space.
6. Created the required folder structure inside the home directory.
7. Created the `about-me.md` Markdown file inside the `Notes` folder.
8. Viewed the Markdown file through the terminal.

## Linux Commands Used

* `ls` – Lists files and directories.
* `cd` – Changes the current directory.
* `pwd` – Displays the current working directory.
* `mkdir` – Creates new directories.
* `cat` – Displays the contents of a file.
* `cat /etc/os-release` – Displays Linux distribution information.
* `lscpu` – Displays CPU information.
* `free -h` – Displays memory information.
* `df -h` – Displays available disk space.

## Skills Learned

Through this laboratory activity, I learned how to navigate and manage files and directories using the Linux terminal. I also learned how to gather important information about a Linux system, including its distribution, kernel, CPU, memory, and disk space. Creating the required workspace and Markdown file helped me practice basic Linux commands and improve my confidence in using the command line. These skills are useful for working with cloud environments and managing Linux-based systems.
